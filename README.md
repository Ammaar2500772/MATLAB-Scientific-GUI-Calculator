# MATLAB Scientific Graphing Calculator
A fully functional graphical user interface (GUI) built using MATLAB App Designer. 

![Calculator Interface](https://github.com/Ammaar2500772/MATLAB-Scientific-GUI-Calculator/blob/main/Calculator%20GUI.png)

## Features:
* **Core Mathematics:** Basic arithmetic, trigonometric functions (sin, cos, tan), logarithms, and square roots.
* **Real-Time Graphing:** Integrated 2D plotting axes that visualize sine, cosine, and tangent waves dynamically based on user input.
* **Robust Evaluation:** Uses event-driven callbacks and `try-catch` blocks to handle syntax errors gracefully without crashing the application.
* **UI/UX Design:** Features clear, backspace, and sign-toggle functionalities for a smooth user experience.
